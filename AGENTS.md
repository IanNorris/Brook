# Brook continuation

Agent working notes are kept outside this repository, in the maintainer's
private notes repo (`/data/Programming/Brook/notes` on the build host). Read
WORKING_STYLE.md and HANDOVER.md there first, check DECISIONS.md before
reopening a settled investigation, use REFERENCE_INDEX.md to find evidence, and
search AGENT_JOURNAL.md (newest first) rather than reading it whole. Keep the
handover current at milestones and before ending a session. Never write agent
notes, handovers or run logs into this repository.

Use the brook-vm skill before operating the Brook debug bridge; the bridge
orientation is in tools/vm_bridge/ORIENTATION.md.
