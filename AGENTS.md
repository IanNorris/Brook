# Brook continuation

For Brook continuation work, read docs/agent/WORKING_STYLE.md and
docs/agent/HANDOVER.md (short current state). Check docs/agent/DECISIONS.md
before reopening a settled investigation. Use docs/agent/REFERENCE_INDEX.md to
find supporting evidence; docs/agent/AGENT_JOURNAL.md is the detailed
append-only run log (newest first) — search it, don't read it whole.
Keep the handover current at milestones and before ending a session.
Use the brook-vm skill before operating the Brook debug bridge MCP; the bridge
orientation is in docs/agent/DEBUG_BRIDGE.md.
